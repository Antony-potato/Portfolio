## The Project

**Koa Towers** is a premium vertical residential development in Cancún by **Onix Living**. The project set out to change how the sales team presents the complex and manages apartment availability, moving from static tools to an immersive, always up-to-date digital experience.

## The Challenge

The client's main operational bottleneck was inventory control. Availability depended on manual updates and constantly exported PDF documents that became outdated right away.

The project had to solve two critical fronts:
1. **Frictionless sync:** keep the inventory updated in real time, with no technical knowledge required from the admin team.
2. **High-end presentation:** build an interactive explorer that conveys the development's exclusivity, clearly showing the towers, floor plans and exact location.

## The Solution

A platform focused on client autonomy and performance:

- **Managed from Google Sheets:** a dynamic data flow where the client only edits a spreadsheet. The site reads it to update colors, status and prices directly on the interactive plans, instantly.
- **Immersive exploration:** a cinematic 3D viewer synced to the user's *scroll*, plus interactive 2D plans with zoom and pan to discover each unit in detail.
- **Precise context:** Google Maps API integration for an elegant, useful location experience for prospects.
- **Lightweight by design:** Astro plus native web technologies instead of heavy frameworks, for smooth navigation on mobile and desktop.

## The Impact

The platform became the development's main digital sales engine:

- **Operational efficiency:** the team stopped using static PDFs entirely and now manages its inventory in one central, secure place.
- **Perceived value:** a fast interface and immersive visuals elevated the product presentation and eased the buying process.
- **Premium experience:** the website reflects the quality and exclusivity Onix Living offers in the physical world.
